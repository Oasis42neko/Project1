## 2. 验收结果填写规则

每一项只填写一个状态：

- **通过**：按步骤验证成功，结果与预期一致。
- **不通过**：功能缺失、报错、数据错误或与预期不一致。
- **部分通过**：主流程可用，但存在已知限制、边界问题或待修复问题。
- **待确认**：需要业务方先确定规则、数据或权限，测试人员不能自行判定。
- **不适用**：当前版本不包含该项，必须填写原因。

“实际结果”不能只写“正常”，应记录关键数量、耗时、编号、错误信息或截图名称。发现问题时，至少记录复现步骤、设备、微信版本和截图/录屏位置。

## 5. 发布前阻断项

以下任意一项未通过，不建议提交正式发布：

- [ ] 云函数未重新部署，或云环境 ID 不一致。
- [ ] 内容安全审核未生效，或审核服务异常时仍能绕过保存。
- [ ] 正常用户无法登录，或普通用户可以越权管理数据。
- [ ] 20 个固定样方不能完整显示，或样方选择无法自动回填坐标。
- [ ] 默认坐标仍为十进制度，或度分秒保存/导出错误。
- [ ] “固定样方以外区域”无法选择、保存或被错误进行固定样方范围校验。
- [ ] 古树总数不是 2300，或“全部”筛选为空。
- [ ] 古树 1883/417 的定位统计不正确，或无坐标记录显示虚假坐标。
- [ ] 古树快速翻页出现明显卡顿、重复数据或旧响应覆盖新响应。
- [ ] 内容安全审核未生效，或审核服务异常时仍能绕过保存。
- [ ] 病虫害页面在空数据时展示演示上报，或正式环境仍可导入演示数据。
- [ ] 资料无法上传、下载、预览，或管理员删除后云文件仍残留。
- [ ] 真机定位、照片上传、权限拒绝、弱网和断网场景导致闪退或数据误保存。
